独立结果复核：官方 DeepPro-Plus 漏检归因

固定阈值 1e-5，以作者协议的目标帧 mask 连通组件计数：
总计 11300 个组件，漏检 1334。近静止组（rel_speed < 0.2）漏检
344/1999 = 17.21%，占全部漏检 25.79%；移动组（>= 0.5）漏检
770/7878 = 9.77%，占全部漏检 57.72%。近静止是较难子集，但不是
漏检数量的主要来源。阈值 0.5 的结论一致：近静止漏检率25.16%，
移动16.62%；近静止只占全部漏检23.34%。这些是关联，不能证明因果。

集中性需要保留：DJI_0237_2 和 DJI_0049_2 贡献317/344 = 92.15%的
近静止漏检。0237本身占近静止组件1615/1999 = 80.79%，但其近静止
漏检率236/1615 = 14.61%，低于移动目标174/899 = 19.35%。因此全局
速度组差异不能直接解释成普遍、独立于场景的机制。

新 profile 的静止相机组内，全部81个近静止漏检都来自DJI_0049_2，
且每个组件都由同一对轨迹3000008;3000007合并组成。按vtdata的类别与
track编码，两者都是类别3（pedestrian）的行人轨迹。它们是同一轨迹对
的重复帧观测，不能表述为81个独立目标，也不能作为跨静止场景的广泛证据。

前四个clip（全部漏检 / 近静止漏检 / 移动漏检）：
DJI_0237_2：508 / 236 / 174
DJI_0049_2：307 / 81 / 173
DJI_0309_4：256 / 2 / 232
DJI_0257_2： 92 / 2 / 84
四者合计1163/1334 = 87.18%的全部漏检。

相机分组敏感性：DJI_0257_2从配置速度0.2842变为新profile的0.350386，
测试运动相机数由6变7。新分组的运动相机漏检927/8037 = 11.53%，
静止相机407/3263 = 12.47%；旧分组分别为835/6911 = 12.08%与
499/4389 = 11.37%。排序会翻转。新运动相机组占漏检69.49%，同时也占
目标组件71.12%；仅看数量集中不能认定相机运动是主要原因。此次没有做
固定权重下的原始/补偿画面对照，补偿收益仍未检验。

独立box指标的补充：clip匹配0.25 FA/frame时，近静止召回914/2850 =
32.07%，移动5329/8373 = 63.65%；1 FA/frame时分别为45.61%与77.39%。
pooled模式0.25 FA/frame时分别为24.07%与54.33%；1 FA/frame时分别为
54.91%与76.16%。近静止较难的观察在这些设置下成立，但pooled并非始终
低于clip模式，不能据此宣称普遍的跨场景校准差距。box计数与作者mask
组件计数不同；rate_analysis相机分组仍来自旧config，不应直接混用。

建议问题表述：官方模型对近静止目标的召回较弱，但近静止目标仅占残余
漏检的一部分，且证据集中于少数场景。MXC针对该困难子集提出场景校准
机制；相机补偿的收益和运动exemplar的额外贡献仍需独立验证。

本次复现为11300个组件中的1334次漏检，官方日志为11303/1362；二者
应分开报告。机器可读计算、来源SHA256及限定见independent_review.json。
